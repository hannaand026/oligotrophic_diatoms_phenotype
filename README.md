# oligotrophic_diatoms_phenotype

## Code used for oligotrophic diatom niche study

## Futher resources

Supplemental files used for analysis are available on Zenodo (https://doi.org/10.5281/zenodo.22999910), along with supplemental figures and additional fasta file.

2015 HOE-Legacy II expedition RNA sequences are available in the National Center for Biotechnology Information Sequence Read Archive (NCBI SRA) in BioProject PRJNA437978.
